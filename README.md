CATS Menu 1.0 — A custom Android mod menu for C.A.T.S. featuring player-only Godmode and 10× damage in one toggle. Personal ARM64 build configured for the gdog543 profile. Unofficial fan project.

Menu features:

• Draggable, minimizable interface

• Separate Godmode and damage-boost controls

• Adjustable 1×–50× damage slider

• Quick presets and reset controls

This is a test build. Gameplay effects and version compatibility are still being verified. Feedback and bug reports are welcome—include your game version, device, and a description of the issue.
